**依赖安装**：Python 3.11；`preprocess.py`（真实实现）需 OpenCV，一条命令 `pip install opencv-python`；`infer.py` / `evaluate.py`（仍假实现）仅需标准库，无需装额外包。

**数据与权重路径**（已下好、不入库，见 .gitignore）：
- toy 数据 `data/toy-examples/`：3 段视频，每段一个 `192x192.mp4` + 一个 `annotation.proto`（约 1GB）；
- 150M 权重 `checkpoints/150M/checkpoint-step=00500000.ckpt`（2.2GB）。

**启动（首跑）**，在仓库根目录依次执行：

```bash
# 1) 数据准备（真实）：读 mp4 + 解析 proto → 200 帧清洗样本 + 统计表
python scripts/preprocess.py --data_dir data/toy-examples --out_dir out --n_frames 200

# 2) 推理（假实现）：全 0 预测
python scripts/infer.py --weights checkpoints/150M/checkpoint-step=00500000.ckpt --samples out/samples.json --out pred

# 3) 评测（假实现）：0.0% / 0.0
python scripts/evaluate.py --pred pred/predictions.json --label out/samples.json
```
