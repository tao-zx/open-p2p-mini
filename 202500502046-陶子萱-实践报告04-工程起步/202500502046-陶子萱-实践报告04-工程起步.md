## .gitignore 逐条说明

| 忽略规则 | 原因 |
|---|---|
| `__pycache__/`、`*.pyc`、`.venv/`、`venv/` | Python 运行残留与依赖目录，可再生成 |
| `*.ckpt`、`*.pt`、`*.pth`、`*.bin` 等 | 模型权重体积大，不入库（保 <10MB） |
| `data/`、`datasets/`、`*.mp4`、`*.proto` | 数据集与标注，体积大且可再下载/另存 |
| `.env`、`*.key`、`*.pem` 等 | 敏感信息（令牌/密码/私钥），绝不入库 |
| `out/`、`pred/`、`metrics.json`、`*.log` | 运行中间产物，可再生成 |
| `.vscode/`、`.idea/`、`.DS_Store` | 编辑器/系统缓存 |
| `实践指导书.pdf`、`第X天要求/`、`*.zip` | 老师课件与截图、打包件，非本人产出 |
