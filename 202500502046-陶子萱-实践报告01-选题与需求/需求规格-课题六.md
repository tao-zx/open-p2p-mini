# 需求规格 —— 课题六：行为克隆游戏智能体（Open Pixel2Play）

## 一、项目概述

本课题基于 Open Pixel2Play（Open P2P）项目，目标是对一个 150M 参数的视觉-语言-动作（VLA）模型进行数据预处理与基线推理，使其能根据游戏画面输出鼠标/键盘动作，并在 `p2p-toy-examples` 数据上达到 **按键准确率 ≥55%、鼠标相关系数 ≥0.5** 的可验收指标。

## 二、用户故事

1. 作为本组开发者，希望理解 Open P2P 150M 模型的输入/输出与推理流程，以便能复现基线推理。
2. 作为本组开发者，希望把 `p2p-toy-examples` 处理成 200 条清洗样本并产出统计指标，以便为推理与评测提供可复用数据。
3. 作为课程验收方，希望运行推理命令后得到按键准确率 ≥55%、鼠标相关系数 ≥0.5 的基线，以便核对基线是否达标。
4. 作为课程验收方，希望在同一测试片段上看到模型输出与人类标注对比，以便核对模型确实在工作。
5. 作为课程验收方，希望拿到含可复现步骤 + 指标表 + 3000 字说明的报告，以便独立复现结果。

## 三、验收句（Given - When - Then）

1. **Given** 已 clone 的 open-p2p 仓库，**When** 阅读 README 并输出理解说明，**Then** 应写清模型输入（游戏画面）、输出（鼠标/键盘动作）、推理数据与命令。
2. **Given** `p2p-toy-examples` 数据已就绪，**When** 运行数据预处理脚本，**Then** 应产出 ≥200 条清洗样本及统计指标表（样本数、动作分布等）。
3. **Given** 清洗后的数据，**When** 运行推理与评测脚本至完成，**Then** 按键准确率 ≥55%、鼠标相关系数 ≥0.5。
4. **Given** 预训练权重，**When** 对同一测试片段推理，**Then** 应输出模型输出与人类标注的对比。
5. **Given** 全部成果，**When** 提交，**Then** 应包含可复现步骤 + 指标表 + 3000 字报告。

## 四、脚本接口约定（设计阶段写清，指导后续编码）

| 脚本 | 输入 | 输出 |
|---|---|---|
| `preprocess.py` | `p2p-toy-examples` 原始数据 | 200 条清洗样本 + 统计指标表 |
| `infer.py` | 预训练 150M 权重 + 清洗样本 | 每帧预测动作 |
| `evaluate.py` | 预测动作 + 人类标注 | 按键准确率、鼠标相关系数 |
| `train.py`（扩展·微调） | 1 款游戏、2 小时数据 | 微调后权重 + 指标对比（按键 +8pp 或 鼠标 +0.08） |

## 五、非功能性说明

- **硬件约束**：主路径推理可 CPU；微调（扩展）需 NVIDIA CUDA，在学校提供的 NVIDIA 服务器完成；本机无 N 卡，CPU 仅兜底推理。
- **可复现**：README 需写精确到版本号（Python / PyTorch / CUDA）+ 安装 / 数据 / 推理 / 评测命令 + 期望输出，并在第 8-9 天按 README 从头验证一遍。
