# 需求规格 —— 课题六：行动世界模型智能体（Open Pixel2Play）

## 一、项目概述

本课题基于 Open Pixel2Play（Open P2P）项目，目标是对一个 150M 参数的视觉-语言-动作（VLA）模型进行数据预处理与训练，使其能根据游戏画面输出鼠标/键盘动作，并在 `p2p-toy-examples` 数据上达到 **按键准确率 ≥55%、鼠标相关系数 ≥0.5** 的可验收指标。

## 二、用户故事

1. 作为本组开发者，希望理解 Open P2P 150M 模型的输入/输出与训练流程，以便能复现并在此基础上完成训练。
2. 作为本组开发者，希望把 `p2p-toy-examples` 处理成 200 条清洗样本并产出统计指标，以便为训练提供可复用数据。
3. 作为课程验收方，希望运行训练命令后得到按键准确率 ≥55%、鼠标相关系数 ≥0.5 的模型，以便核对训练是否达标。
4. 作为课程验收方，希望对 5 条测试样本做推理并看到预测动作与真值对比，以便核对模型确实在工作。
5. 作为课程验收方，希望拿到含可复现步骤 + 指标表 + 3000 字说明的报告，以便独立复现结果。

## 三、验收句（Given - When - Then）

1. **Given** 已 clone 的 open-p2p 仓库，**When** 阅读 README 并输出理解说明，**Then** 应写清模型输入（游戏画面）、输出（鼠标/键盘动作）、训练数据与命令。
2. **Given** `p2p-toy-examples` 数据已就绪，**When** 运行数据预处理脚本，**Then** 应产出 ≥200 条清洗样本及统计指标表（样本数、动作分布等）。
3. **Given** 清洗后的数据，**When** 运行训练命令至完成，**Then** 按键准确率 ≥55%、鼠标相关系数 ≥0.5。
4. **Given** 训练好的权重，**When** 对 5 条测试样本推理，**Then** 应输出每条预测动作与真值的对比表。
5. **Given** 全部成果，**When** 提交，**Then** 应包含可复现步骤 + 指标表 + 3000 字报告。

## 四、脚本接口约定（设计阶段写清，指导后续编码）

| 脚本 | 输入 | 输出 |
|---|---|---|
| `preprocess.py` | `p2p-toy-examples` 原始数据 | 200 条清洗样本 + 统计指标表 |
| `train.py` | 清洗后样本 | 训练日志 + checkpoint 权重 + 验证集指标 |
| `infer.py` | checkpoint 权重 + 5 条测试样本 | 预测动作 vs 真值对比表 |

## 五、非功能性说明

- **硬件约束**：训练需 NVIDIA CUDA；本机无 N 卡，训练在学校提供的 NVIDIA 服务器或 CPU 降级完成；推理可 CPU 降级。
- **可复现**：README 需写精确到版本号（Python / PyTorch / CUDA）+ 安装 / 数据 / 训练 / 推理命令 + 期望输出，并在第 8-9 天按 README 从头验证一遍。
