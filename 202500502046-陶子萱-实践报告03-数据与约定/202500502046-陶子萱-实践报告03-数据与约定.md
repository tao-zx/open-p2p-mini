## 一、数据模型（主路径实体与字段）

主路径（第 1 天定、第 5 天演示）：

```
toy 原始数据 → 预处理 → 清洗样本(200 帧) → 推理(150M) → 预测动作 → 评测 → 指标(按键准确率/鼠标相关系数) → 演示
```

按老师要求，实验类课题按「数据切片、指标记录」对象写，不必套 Web 分层。主路径上持久化两类对象：

### 实体 1：样本切片 Sample（含逐帧动作 FrameAction）

对应「清洗样本」——从 toy 视频切出的帧序列 + 逐帧人类动作标注。**每条样本 = 1 帧画面 + 1 条动作标注，200 条样本 = 200 帧测试集。**

| 字段 | 类型 | 含义 | 出处 |
|---|---|---|---|
| video_id | string | 视频唯一标识 | 官方 proto `metadata.id` |
| env | int | 游戏环境编码 | 官方 proto `metadata.env.env` / `env_subtype` |
| frames | (T, 192, 192, 3) uint8 | T 帧画面序列 | 官方 config `frame_height=192`、`frame_width=192` |
| frame_annotations | list[FrameAction] | 逐帧动作标注 | 官方 proto `frame_annotations` |

**逐帧动作 FrameAction**（评测直接用它）：

| 字段 | 类型 | 含义 | 出处 |
|---|---|---|---|
| keys | list[int] | 该帧按下的键盘键码 | 官方 `user_action.keyboard.keys` |
| mouse_buttons | list[int] | 该帧按下的鼠标键码 | 官方 `user_action.mouse.buttons_down` |
| mouse_delta_x | int | 鼠标水平位移 | 官方 `user_action.mouse.mouse_delta_px.x` |
| mouse_delta_y | int | 鼠标垂直位移 | 官方 `user_action.mouse.mouse_delta_px.y` |
| is_user_action | bool | 是否人类动作 | 官方 `user_action.is_known` / `user_action_mask` |

说明：逐帧标注同时含 `user_action`（人类）与 `system_action`（系统动作），评测只取 `is_known` 为真的人类动作，忽略系统动作，避免误判。

### 实体 2：指标记录 MetricRecord

对应「评测结果」，是验收判据的持久化对象，演示与结课报告都从这里取值。

| 字段 | 类型 | 含义 | 验收阈值 |
|---|---|---|---|
| key_accuracy | float | 按键准确率 | ≥55% |
| mouse_correlation | float | 鼠标相关系数 | ≥0.5 |
| n_samples | int | 评测样本数 | 200 |
| action_distribution | dict | 动作分布统计 | 供统计表 |

字段一致性：三处（preprocess 产出 / infer 读入 / evaluate 读入）字段名统一为英文名，与官方代码同名，无需另做字段对照表。

## 二、接口约定

本课题是 CLI 脚本，接口约定 = 命令 + 参数 + 成功/失败返回。三个主路径脚本：

| 脚本 | 命令 | 成功返回 | 失败返回 |
|---|---|---|---|
| `preprocess.py` | `--data_dir` `--out_dir` `--n_frames 200` | 退出码 0，写出 samples.json + stats.csv | 数据目录不存在 → 退出码 3 |
| `infer.py` | `--weights` `--samples` `--out` | 退出码 0，写出 predictions.json | 权重缺失 → 退出码 2 |
| `evaluate.py` | `--pred` `--label` | 退出码 0，打印两指标 + 写 metrics.json | 帧数不一致 → 退出码 3 |

**成功例（评测）：**

```
$ python evaluate.py --pred pred/predictions.json --label out/samples.json
[OK] 按键准确率 = 58.0% （阈值 55%）
[OK] 鼠标相关系数 = 0.52 （阈值 0.5）
[OK] 写出 metrics.json
```

**失败例（评测，帧数不一致）：**

```
$ python evaluate.py --pred pred/predictions.json --label out/samples.json
[ERROR] 预测 199 帧 vs 标注 200 帧，帧数不一致（退出码 3）
```
