# 数据模型（第 3 天 · 数据与约定）

> 主路径上要持久化的数据。按老师要求，实验类课题按「数据切片、指标记录」等对象写，不必套 Web 分层。字段全部来自官方仓库源码，已逐条核对出处，不编造。

## 一、主路径是什么

第 1 天定下、第 5 天必须演示的主路径（见立项书 5.3 数据流、需求规格四）：

```
toy 原始数据 → 预处理 → 清洗样本(200 帧) → 推理(150M) → 预测动作 → 评测 → 指标(按键准确率/鼠标相关系数) → 演示
```

主路径上需要持久化两类对象：**样本切片**（预处理的产物，推理与评测共用）和**指标记录**（评测的产物，即验收判据）。

## 二、实体与字段

### 实体 1：样本切片 Sample（含逐帧动作 FrameAction）

对应「清洗样本」——从 toy 视频切出的帧序列 + 逐帧人类动作标注。**每条样本 = 1 帧画面 + 1 条动作标注，200 条样本 = 200 帧测试集。**

| 字段 | 类型 | 含义 | 出处 |
|---|---|---|---|
| video_id | string | 视频唯一标识 | 官方 proto `metadata.id` |
| env | int | 游戏环境编码（环境 + 子类型） | 官方 proto `metadata.env.env` / `env_subtype` |
| frames | (T, 192, 192, 3) uint8 | T 帧画面序列 | 官方 config `frame_height=192`、`frame_width=192` |
| frame_annotations | list[FrameAction] | 逐帧动作标注，长度 = 帧数 | 官方 proto `frame_annotations` |

**逐帧动作 FrameAction**（评测直接用它，是本课题最核心的字段）：

| 字段 | 类型 | 含义 | 出处 |
|---|---|---|---|
| keys | list[int] | 该帧按下的键盘键码 | 官方 `user_action.keyboard.keys` |
| mouse_buttons | list[int] | 该帧按下的鼠标键码 | 官方 `user_action.mouse.buttons_down` |
| mouse_delta_x | int | 鼠标水平位移（像素） | 官方 `user_action.mouse.mouse_delta_px.x` |
| mouse_delta_y | int | 鼠标垂直位移（像素） | 官方 `user_action.mouse.mouse_delta_px.y` |
| is_user_action | bool | 是否人类动作（区分系统动作） | 官方 `user_action.is_known` / `user_action_mask` |

说明：逐帧标注里同时存在 `user_action`（人类动作）与 `system_action`（系统动作，如镜头自动旋转），评测时只取 `is_known` 为真的用户动作，忽略系统动作，避免误判。

### 实体 2：指标记录 MetricRecord

对应「评测结果」，是验收判据的持久化对象，第 5 天演示与结课报告都从这里取值。

| 字段 | 类型 | 含义 | 验收阈值 |
|---|---|---|---|
| key_accuracy | float | 按键准确率 | ≥55% |
| mouse_correlation | float | 鼠标相关系数（x/y 位移的相关系数） | ≥0.5 |
| n_samples | int | 评测样本数 | 200 |
| action_distribution | dict | 动作分布（各键 / 各鼠标键频次） | 供统计表 |

## 三、字段一致性

老师要求「库表、接口、前端（本课题指各脚本）三处字段名一致」。本课题三处是：preprocess 产出 → infer 读入 → evaluate 读入。字段名统一用上表英文名（`keys` / `mouse_buttons` / `mouse_delta_x` / `mouse_delta_y`），与官方代码保持同名，减少转换错误；无需另做字段对照表。

## 四、出处说明

字段全部来自官方仓库两个源码文件（已核对）：

- `elefant/data/video_proto_dataset.py`：视频 + proto 存储方式、`metadata.id`、`frame_annotations`、`frame_height=192` / `frame_width=192`、`T=10`（默认每块帧数）。
- `elefant/data/action_label_video_proto_dataset.py`：逐帧动作字段 `keyboard.keys`、`mouse.buttons_down`、`mouse.mouse_delta_px`，转张量后的四字段 `keys` / `mouse_buttons` / `mouse_delta_x` / `mouse_delta_y`；以及 `user_action` / `system_action` / `is_known` 的区分逻辑。
