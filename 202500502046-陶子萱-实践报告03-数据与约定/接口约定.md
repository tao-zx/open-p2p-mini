# 接口约定（第 3 天 · 数据与约定）

> 写入仓库、供各脚本共同遵守的调用说明。每个脚本写清：命令（方法）、参数、成功与失败时返回什么。未写明的行为不得各自猜测。

## 一、退出码规则（统一约定）

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 2 | 参数错误（参数缺失 / 值非法） |
| 3 | 数据/文件错误（文件不存在 / 内容对不上） |

## 二、主路径与“最关键的一步”

主路径四步：数据准备 → 推理 → 评测 → 演示。其中**最关键的一步是 `infer.py`（推理）**——它是“看画面 → 出动作”的核心，也是第 5 天演示的主角。下面把它作为完整范例写清，其余脚本用同一格式。

## 三、脚本调用约定

### 1. `infer.py` —— 推理（主路径最关键一步，完整范例）

- 命令：`python infer.py --weights <150M权重> --samples <samples.json> --out <预测目录>`
- 参数：
  - `--weights`：150M 模型权重文件路径
  - `--samples`：preprocess 产出的 `samples.json` 文件
  - `--out`：预测输出目录
- 成功返回：退出码 0；写出 `predictions.json`（每帧的 `keys` / `mouse_buttons` / `mouse_delta_x` / `mouse_delta_y`）
- 失败返回：退出码非 0；stderr 打印原因

**成功一例：**

- 输入要点：`--weights` 指向已下载的 150M 权重；`--samples` 指向 `samples.json`（200 条样本）
- 输出要点：`predictions.json`，200 帧每帧 4 个动作字段（`keys` / `mouse_buttons` / `mouse_delta_x` / `mouse_delta_y`）

```
$ python infer.py --weights ckpt/150m.pt --samples out/samples.json --out pred
[OK] 推理 200 帧完成
[OK] 写出 pred/predictions.json
```

**失败一例（权重文件缺失）：**

```
$ python infer.py --weights no_ckpt.pt --samples out/samples.json --out pred
[ERROR] 权重文件不存在: no_ckpt.pt（退出码 3）
```

### 2. `preprocess.py` —— 数据准备

- 命令：`python preprocess.py --data_dir <toy数据> --out_dir <输出> --n_frames 200`
- 参数：
  - `--data_dir`：toy 数据目录（含 `.mp4` 视频 + `.proto` 标注）
  - `--out_dir`：输出目录
  - `--n_frames`：测试集帧数，默认 200
  - 帧尺寸固定 192×192，写死在代码里，不再作为参数
- 成功返回：退出码 0；写出 `samples.json`（帧 + 动作标注）与 `stats.csv`（统计表）
- 失败返回：退出码非 0；stderr 打印原因

**成功一例：**

- 输入要点：`--data_dir` 指向含 `.mp4` + `.proto` 的 toy 目录，`--n_frames 200`
- 输出要点：`samples.json`（200 条样本）+ `stats.csv`（样本数 / 动作分布）

```
$ python preprocess.py --data_dir toy-examples --out_dir out --n_frames 200
[OK] 处理 200 帧 → 产出 200 条样本
[OK] 写出 out/samples.json、out/stats.csv
```

**失败一例（参数错误）：**

```
$ python preprocess.py --data_dir toy-examples --out_dir out --n_frames -5
[ERROR] --n_frames 必须是正整数，收到 -5（退出码 2）
```

**失败一例（数据目录不存在）：**

```
$ python preprocess.py --data_dir no_such_dir --out_dir out
[ERROR] 数据目录不存在: no_such_dir（退出码 3）
```

### 3. `evaluate.py` —— 评测

- 命令：`python evaluate.py --pred <predictions.json> --label <samples.json>`
- 参数：
  - `--pred`：infer 产出的 `predictions.json`
  - `--label`：preprocess 产出的 `samples.json`（内含真人标注）
- 成功返回：退出码 0；打印两个指标，写出 `metrics.json`
- 失败返回：退出码非 0；stderr 打印原因

**成功一例：**

- 输入要点：`--pred` 与 `--label` 两个文件，帧数一致
- 输出要点：按键准确率 + 鼠标相关系数 + `metrics.json`

```
$ python evaluate.py --pred pred/predictions.json --label out/samples.json
[OK] 按键准确率 = 58.0% （阈值 55%）
[OK] 鼠标相关系数 = 0.52 （阈值 0.5）
[OK] 写出 metrics.json
```

**失败一例（预测与标注帧数不一致）：**

```
$ python evaluate.py --pred pred/predictions.json --label out/samples.json
[ERROR] 预测 199 帧 vs 标注 200 帧，帧数不一致（退出码 3）
```
