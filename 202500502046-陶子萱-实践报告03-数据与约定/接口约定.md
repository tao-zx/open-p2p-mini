# 接口约定（第 3 天 · 数据与约定）

> 写入仓库、供各脚本共同遵守的调用说明。每个脚本写清：命令（方法）、参数、成功与失败时返回什么。未写明的行为不得各自猜测。

## 一、约定对象

本课题是 CLI 脚本，接口约定 = 每个脚本的「命令 + 参数 + 成功/失败返回」。共三个主路径脚本 + 一个扩展脚本。

## 二、脚本调用约定

### 1. `preprocess.py` —— 数据准备

- 命令：`python preprocess.py --data_dir <toy数据> --out_dir <输出> --n_frames 200`
- 参数：
  - `--data_dir`：toy 数据目录（含 `.mp4` 视频 + `.proto` 标注）
  - `--out_dir`：清洗样本输出目录
  - `--n_frames`：测试集帧数，默认 200
  - `--height` / `--width`：帧尺寸，默认 192 / 192
- 成功返回：退出码 0；stdout 打印处理结果；写出 `samples.json`（帧 + 动作标注）与 `stats.csv`（样本数 / 动作分布）
- 失败返回：退出码非 0（2=参数错，3=数据错）；stderr 打印原因

**成功例：**

```
$ python preprocess.py --data_dir toy-examples --out_dir out --n_frames 200
[OK] 处理 200 帧 → 产出 200 条样本
[OK] 写出 out/samples.json、out/stats.csv
```

**失败例（数据目录不存在）：**

```
$ python preprocess.py --data_dir no_such_dir --out_dir out
[ERROR] 数据目录不存在: no_such_dir（退出码 3）
```

### 2. `infer.py` —— 推理

- 命令：`python infer.py --weights <150M权重> --samples <样本> --out <预测>`
- 参数：
  - `--weights`：150M checkpoint 权重路径
  - `--samples`：`preprocess.py` 产出的样本目录
  - `--out`：预测输出路径
- 成功返回：退出码 0；写出 `predictions.json`，每帧含 `keys` / `mouse_buttons` / `mouse_delta_x` / `mouse_delta_y`
- 失败返回：退出码非 0（权重缺失 / 样本帧尺寸不符）；stderr 打印原因

**成功例：**

```
$ python infer.py --weights ckpt/150m.pt --samples out --out pred
[OK] 推理 200 帧完成
[OK] 写出 pred/predictions.json
```

**失败例（权重缺失）：**

```
$ python infer.py --weights no_ckpt.pt --samples out --out pred
[ERROR] 权重文件不存在: no_ckpt.pt（退出码 2）
```

### 3. `evaluate.py` —— 评测

- 命令：`python evaluate.py --pred <预测> --label <标注>`
- 参数：
  - `--pred`：`infer.py` 产出的 `predictions.json`
  - `--label`：`preprocess.py` 产出的标注（`samples.json` 内动作字段）
- 成功返回：退出码 0；stdout 打印两个指标，并写出 `metrics.json`（含 `key_accuracy`、`mouse_correlation`、`n_samples`）
- 失败返回：退出码非 0；stderr 打印原因

**成功例：**

```
$ python evaluate.py --pred pred/predictions.json --label out/samples.json
[OK] 按键准确率 = 58.0% （阈值 55%）
[OK] 鼠标相关系数 = 0.52 （阈值 0.5）
[OK] 写出 metrics.json
```

**失败例（预测与标注帧数不一致）：**

```
$ python evaluate.py --pred pred/predictions.json --label out/samples.json
[ERROR] 预测 199 帧 vs 标注 200 帧，帧数不一致（退出码 3）
```

### 4. `train.py` —— 微调（扩展）

- 命令：`python train.py --data_dir <微调数据> --out_dir <输出> --epochs <轮数>`
- 成功返回：退出码 0；写出训练日志 + checkpoint 权重 + 验证集指标
- 失败返回：退出码非 0；stderr 打印原因
- 注意：微调数据来源与「不得下载 full-data 全库」冲突，待问老师（见项目备忘），故本脚本仅留接口、暂不落地。

## 三、临时假实现边界

第 3 天只定约定、不写真实逻辑。第 4-5 天先用「临时假实现」占位，**所有假实现必须在文件顶部与每个函数用 `# TODO(假实现)` 标明，并返回固定假数据**，便于归档时一眼识别替换：

| 脚本 | 假实现行为 | 标明方式 |
|---|---|---|
| `preprocess.py` | 返回固定 200 条空样本（动作全 0） | 文件头 + 函数 `# TODO(假实现)` |
| `infer.py` | 返回全 0 动作 | 同上 |
| `evaluate.py` | 返回 0% / 0.0 | 同上 |

约定：真实实现落地后删除对应 `# TODO(假实现)` 标记；归档时若还带此标记，一律不得当作已接真实实现。
