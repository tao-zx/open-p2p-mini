## 他人如何启动

分条写安装、配置、启动、停止；只看本节，他人也能尝试运行或复现。

**安装（环境 + 依赖）**
1. 准备 GPU 服务器（本项目用 NVIDIA Quadro RTX 6000 24GB）+ 官方 open-p2p 仓库（含 `elefant` 包）。
2. 建 venv：`uv sync --extra gpu`（依赖固定见 `pyproject.toml` + `依赖清单.md`；`elefant` 非 pip 包，由脚本 `--official-repo` 指路）。
3. 获取数据与权重：toy 数据（`p2p-toy-examples`）与 150M 权重 `checkpoint-step=00500000.ckpt`（2.2GB）+ `model_config.yaml`（获取见 `开发日志.md` 第 4 天）。

**配置**：当前无需环境变量，数据/权重路径均经命令行参数传入。

**启动**（在任意工作目录下执行，路径为示例 `/root/workspace/taozixuan/`；`python` 用 open-p2p venv）：
```bash
python scripts/preprocess.py --data_dir data/p2p-toy-examples --out_dir out --n_frames 200
python scripts/infer.py --weights checkpoints/150M/checkpoint-step=00500000.ckpt \
  --samples out/samples.json --out pred --official-repo <open-p2p仓库> --mode teacher_forcing
python scripts/evaluate.py --pred pred/predictions.json --label out/samples.json --out metrics.json
```
预期：`[OK] 处理 200 帧` → `[OK] 推理 200 帧完成` → `[OK] 按键准确率 = 88.0%（阈值 55%）`、`[OK] 鼠标相关系数 = 0.756（阈值 0.5）`。启动成功后按第 5 天工作流程走主路径（见 `演示说明.md`）。

**停止与回退**：三脚本均为“运行即结束”的短命令，无常驻服务，中途中断按 `Ctrl+C`（唯一例外 `free_running` 约 13 分钟）；若微调权重加载报错或指标退化，把 `infer.py --weights` 换回 150M 基线权重即可恢复基线 88.0% / 0.756。
